# Project: ForensIQ

## What This Is
ForensIQ is an AI-powered media forensics, tampering detection, and deepfake verification platform. It provides interactive image/video analysis, before/after comparative inspection, authenticity probability timelines, and visual artifact reporting.

## Core Requirements
- Modern, high-performance web UI built with React + Vite + TypeScript.
- Forensic comparison tools (interactive slider comparison, side-by-side artifact inspection).
- Media dropzone supporting high-resolution image and video ingestion.
- Frame-by-frame and anomaly metrics powered by interactive charting (`recharts`).
- Sleek, dark cyber-forensic interface adhering to UI/UX Pro Max guidelines.

## Out of Scope (V1)
- Heavy server-side video slicing backend (mock/API contract in V1).
- Multi-tenant enterprise SSO (local/direct use in V1).

## Technical Stack & Constraints
- **Frontend**: React 18, Vite, TypeScript, Tailwind CSS
- **Interactive UI**: `lucide-react`, `clsx`, `tailwind-merge`, `framer-motion`, `react-dropzone`, `react-compare-image`, `recharts`
- **Methodology**: GSD (Get Shit Done) spec-driven lifecycle
- **Design Intelligence**: UI/UX Pro Max skill suite
